# MatchApp 2.0.4 Supabase

For a new Supabase project, run:

1. `setup_matchapp_2_0_4.sql`

The files in `archive/` are older migration/fix snippets kept for history. Do not run them one by one for a fresh 2.0.4 setup unless you are deliberately investigating old database changes.

Seed files are archived because they contain environment-specific users/teams and should not be applied automatically to test or production.
